# Relay Tester Android 1.7.1

发布日期：2026-10-05

## 更新内容

### 修复

- **修复打开应用不自动检查更新**：以前启动还要等满距上次检查六小时才查，现在勾选了自动检查就每次打开都查，两处「上次检查」随这次刷新。

### 优化

- **有更新自己把页面打开**：发现新版本时「关于与更新」自动弹出，检测包新版则「更新检测包」按钮直接就位，同一版本只自动打开一次。
- **更新说明直接印在更新页里**：发行说明以纯文本显示在页面内、最多三成屏高可自滚，不再只有跳浏览器的链接。
- **弹窗跟着屏幕走**：弹窗高度随内容自适应、横屏下按钮不再被裁到屏幕外，内容盒避开系统栏与挖孔。
