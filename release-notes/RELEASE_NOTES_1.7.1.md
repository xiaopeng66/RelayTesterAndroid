# Relay Tester Android 1.7.1

发布日期：2026-10-05

## 更新内容

### 修复

- **修复打开应用不自动检查更新**：勾选了自动检查时，现在每次打开应用都会在后台检查一次软件更新与检测包更新，两处的「上次检查」随这次检查刷新。以前打开应用还要等满上一次检查过后的六小时，期间什么都不查，「上次检查」也停在上一回的时间。

### 优化

- **有更新自己把页面打开**：后台检查发现软件新版本时，「关于与更新」页面会自动弹出，「下载并安装」就摆在页面上；检测包发现新版本时，检测包卡片上的「更新检测包」按钮同样直接就位。同一个版本在一次使用中只自动打开一次，手动关掉后不会再被反复弹出。
- **更新说明直接印在更新页里**：发现新版本时，发行说明以纯文本直接显示在「关于与更新」页面内（最多占三成屏高、自己滚动），不再只有一枚要跳浏览器的链接；说明盒带不下的完整版仍可一键在浏览器打开。清单里没有说明文本的老清单照旧回落到链接。
- **弹窗跟着屏幕走**：供应商配置弹窗的高度随内容自适应（最高九成屏高、卡片内滚动），横屏下「保存/关闭」不再被裁到屏幕外；「关于与更新」与供应商配置两个弹窗的内容盒同时按横屏的系统栏与挖孔收窄，卡片右缘不再被屏幕切掉。

## 说明

- 检测结果是参考库内的封闭集合排序，不是身份证明：不在库中的模型同样会得到最接近的候选，同家族相邻版本尤其难以区分。
