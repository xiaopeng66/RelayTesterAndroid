# Relay Tester Android 1.2.0

发布日期：2026-09-08

## 更新内容

### 新增功能

- **模型测试**：新增批量拉取模型，可并行刷新所有已配置供应商并显示完成进度；已配置模型支持单个来源测试，多个来源可同时测试。
- **高级测试**：支持跨供应商关键词检索，显示模型来源并可勾选批量添加；编辑已配置模型时已添加的来源保持选中并锁定，移除后自动释放。
- **测试结果**：卡片只显示可用、HTTP 状态码或失败类型；同一来源测试中保留旧结果并显示进行中，进度条固定在来源摘要行。
- **余额查询**：余额卡保持双栏布局，长余额、分组与编辑按钮稳定避让；批量查询支持并行。
- **配置备份**：导入导出支持加密与不加密两种模式。

### 修复

- 修复站点保存提示遮挡关闭与保存按钮、以及提示顶部被窗口边界裁切的问题。
- 修复并行测试状态不同步、异常后来源一直显示进行中、批量拉取成功计数竞态与失败路径重复推进进度的问题。
