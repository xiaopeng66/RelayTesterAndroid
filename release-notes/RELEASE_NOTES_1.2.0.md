# Relay Tester Android 1.2.0

发布日期：2026-09-08

## 更新内容

### 新增功能

- **模型测试**：新增批量拉取模型，并行刷新全部供应商并显示进度。
- **高级测试**：支持跨供应商关键词检索，可勾选批量添加模型来源。
- **测试结果**：卡片显示更简洁，同一来源测试时保留旧结果并标注进行中。
- **余额查询**：批量查询支持并行。
- **配置备份**：导入导出支持加密与不加密两种模式。

### 修复

- 修复保存提示遮挡按钮、顶部被窗口裁切的问题。
- 修复并行测试状态不同步与批量拉取进度错乱的问题。
