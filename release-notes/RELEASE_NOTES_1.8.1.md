# Relay Tester Android 1.8.1

发布日期：2026-10-13

修好供应商排序拖动的闪屏与断触，指纹检测改用上游新版公式，检测包的自动更新也不再失败。

## 更新内容

### 修复

- **供应商排序拖动不再闪屏、不再断触**：手势改挂在列表盒上、被拖的行画成浮层、顺序在松手时写一次，行不再被回收带走手势，也不再和滚动抢同一帧。
- **指纹检测改用上游新版公式**：检测包按上游 `shared-detector-v2` 重建，排名改为频率与位置两半各占一半——此前是拿新版数据按旧公式打分，排名与置信度都不准。
- **检测包自动更新不再失败**：上游把检测器资产换成了二进制 `shared_detector.bin`，脚本只认 JSON 名、已连续三天失败；现在两种资产名都支持，二进制也照读。
- **下载被截断不再当成成功**：按 `Content-Length` 校验字节数，不足就按临时故障重试。
- **不认识的检测包会明确拒绝**：包里写入上游 schema 名，比本版 App 新的包直接拒绝安装并提示更新 App。

### 优化

- **旧检测包照常可用**：已装的 003 / 002 包仍按各自原来的公式评分，只有更新到新包才切到 v2 公式。
- **新包要求本版 App**：格式版本 4 的包要求版本代码 ≥ 10801，也就是这一版。
