# Relay Tester Android 1.8.1

发布日期：2026-10-13

?> 对比基准：GitHub 上一个发行版 **v1.8.0**。本版根治了供应商拖动到边缘的闪屏与断触，并把「模型指纹检测」对齐上游 lm-detector 的新版检测器，同时修好连挂几天的检测包自动更新任务。

## 更新内容

### 修复

- **供应商排序拖动不再闪屏、不再断触**：拖动改成「手势挂在列表盒上、被拖的行画成浮层、松手才写一次顺序」。此前手势挂在行上，而列表会把划出视口的行整个回收——行没了，挂在它身上的手势跟着消失，手指还在屏幕上却拖不动（拖不到最顶或最底）；每跨一格写一次列表又会让列表跟着滚动锚点挪窗口，为压住它还得每帧把窗口钉回去，两个写手抢同一帧，边缘那一段就一直在闪。现在整次拖动只写一笔，松手时落地，列表几何全程不变。
- **指纹检测改用上游新版公式**：检测包改用上游 `shared-detector-v2` 重建。v2 在原「频率」一侧之外增加了一个「位置判别头」（位置核 102 维 + 序列特征 220 维，合计 751 维），并把排名改为**频率与位置两半各占一半**相加，两半都先做 z 标准化——置信度的温度 `tau` 也是按混合后的尺度拟合的。此前线上发布的包本就是用新版数据构建的（57 个模型、参考库 2026-10-08），却按旧公式打分，等于「用错公式算对的数字」，排名与置信度都不准。
- **检测包自动更新任务不再失败**：上游 2026-10-11 把检测器资产从 `shared_detector.json` 换成了二进制 `shared_detector.bin`，脚本只认 JSON 文件名，于是每次运行都在 404 上按「永久失败」退出（6 秒即挂，连续三天）。现已同时支持两种资产名并解码二进制格式（已逐字节核对：与 JSON 时代的 1,026,549 个浮点数完全一致）。
- **下载被截断不再当成成功**：上游下载此前出现过一次「连接正常结束但只收到 1.6MB / 4.2MB」的静默截断，截断的包会一路进到构建器。现在按 `Content-Length` 校验字节数，不足即按临时故障重试。
- **不认识的检测包会明确拒绝**：包里现在写入上游 schema 名，比本版 App 认识的更新时直接拒绝安装并提示更新 App——被错的公式算出「看起来正常」的排名，比直接报错糟糕得多。

### 优化

- **旧检测包照常可用**：设备上已下载的旧格式包（003 / 002）仍按各自原来的公式评分，未重新下载的用户行为完全不变；只有主动更新到新包才切到 v2 公式，此时 App 版本要求为 10801（本版）。
- **检测包发布侧一并升级**：清单格式版本 4 对应新包；发布时要求的最低 App 版本同步提到 10801。
