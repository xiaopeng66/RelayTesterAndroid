# Relay Tester Android 1.6.0

发布日期：2026-10-04

## 更新内容

### 新增功能

- **应用内更新**：顶栏「关于与更新」显示当前版本与版本代码、线上可更新到的版本与安装包大小、下载字节进度，下载完按体积与 SHA-256 校验后交给系统安装界面。
- **自动检查的节律**：打开 App 时查一次，此后 App 常开时每 6 小时再查一次（间隔按落盘的时间戳算），开关关掉后只有主动点按钮才联网。
- **手动检查优先**：正在自动检查时点「检查更新」会立刻接管，不会排在自动检查后面等它结束。
- **检测包状态可见**：检测包卡片显示「正在检查更新…」「上次检查：今天 14:32 · 已是最新」「上次检查失败」，下载时显示字节进度条。
- **两个自动检测开关**：指纹面板的「自动检查检测包更新」与更新页的「自动检查软件更新」，默认都开。
- **安装权限在下载之前问**：没有「安装未知应用」权限时先跳系统授权页，不会先下完安装包再被告知缺权限。
- **更新页给出仓库地址**：弹窗底部是一行可点击的 GitHub 项目地址。
- **安装包**：包名 `com.relaytester.app`；从任意已发布版本可直接覆盖升级，不必卸载重装。

### 优化

- **文案精简**：指纹面板、更新弹窗、模型测试与余额查询里只保留会随状态变化的信息，纯说明性文字一律去掉。
- **检测包构建时间**：改为按本机时区显示到分钟（如 `2026-10-03 15:40`），不再原样打印上游带小数秒的 ISO 串。
- **检测包卡片按钮**：「检查更新」与「删除检测包」并排等宽两栏，文字不换行。
- **加载状态只画一处**：手动检查时状态行保持上一次结果，转圈只出现在按钮上。
- **已配置模型卡片**：四个动作按钮收紧到右侧、去掉按下时的选中虚影，图标尺寸不变。
- **检索按钮对齐**：模型检索框右侧的「检索」按钮改为与输入框底边对齐（按布局盒居中会显得偏高）。
- **「关于与更新」弹窗随内容收缩**：删掉检测包卡片后不再留一大片空白，高度按内容算（上限仍是屏幕高度的九成）。
- **三道题目的「重试」对齐同一排**：失败理由占 0/1/2 行时按钮都贴格子底边，三格等高时三枚按钮水平高度一致。
- **报错文字统一字重**：失败理由改用常规字重，中文不再比英文看着粗。
- **大字号下的按钮文字**：系统字号 2.0× 时「删除检测包」等按钮按栏宽自动缩排，不再出现省略号。
- **自动检查只在启动时触发一次**：指纹面板不再每切一次页面就重新检查检测包更新。

### 修复

- 修复线上检测包要求更高版本 App 时只报一个格式版本号的问题，现在给一句可执行的话并配「去更新软件」直达更新页。
- 修复更新通道的提示（发现新版本、失败原因、安装错误）没有任何界面在读的问题。
- 修复 `optimized` 变体的版本名带 `-optimized` 后缀、在更新页读起来像另一个版本的问题。

## 说明

- 检测结果是**参考库内的封闭集合排序，不是身份证明**：不在库中的模型同样会得到最接近的候选，同家族相邻版本尤其难以区分。
- 应用自身更新的下载链路**不使用**供应商请求那条同源重定向策略，因为 GitHub 的资产会跳到 `objects.githubusercontent.com` 而这条链路不携带任何凭据。
- 移植自 [lm-detector](https://github.com/Ikaleio/lm-detector)（MIT License, Copyright (c) 2026 xqy2006），检测包算法与上游 `shared-detector-v1` 对齐，端侧实现与参数量化带来的差异已在 `THIRD_PARTY_NOTICES.md` 中如实声明。
