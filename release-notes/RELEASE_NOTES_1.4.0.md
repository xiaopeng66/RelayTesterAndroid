# Relay Tester Android 1.4.0

发布日期：2026-10-01

## 更新内容

### 新增功能

- **指纹检测（新页签）**：让模型凭第一反应写出约 300 个整数，与离线参考库比对判断实际响应的是哪个模型，用于核对中转站是否偷换模型。
- **参考库更新**：面板卡片显示库的构建时间、模型数与来源，支持检查更新、更新与恢复内置库，下载后按大小与 SHA-256 校验再安装。
- **两种检测模式**：API 直连从已配置供应商一键出题分析，没有密钥时手动复制题目、把回答粘回来。
- **模型选择**：模型名输入框兼筛选，可多选并按勾选顺序逐个检测，目录里没有的名字可直接输入。
- **逐题状态与重试**：每道题单独显示接收状态与识别到的整数个数，未达标可只重试本题。
- **并行开关**：默认三题并行，慢速站点可关闭改为逐题发送。
- **结果展示**：给出最接近的候选、所属家族与置信度，以及按分数排序的候选列表。
- 三道探测题每次随机生成（多语言、长度随机且互不相同），降低被缓存或模板化应答命中的可能。
- 模型测试中测试成功的模型带指纹图标，点击即带着供应商与模型名跳转指纹面板。
- 测试模式与供应商的选中态统一为蓝色实心标签，选中哪一个一眼可辨。

### 修复

- 修复手动粘贴模式下输入框无法保留文字、手动检测实际不可用的问题。
- 修复「重新生成题目」按钮空转的问题。
- 修复粘贴未达标回答时各题状态不更新的问题。
- 修复留空的输入框被误判为「有效数字不足」的问题。
- 修复手动模式下顶部计数始终显示 0/3 的问题。
- 修复 API 直连失败后原因与重试入口消失的问题。
- 修复并行开关可能被忽略的问题。
- 修复失败卡片重复显示同一句话的问题。
- 修复在模型测试里拉取模型后切回指纹面板仍显示空目录的问题。
- 修复目录刷新丢勾选、刷新失败把面板变成整页错误的问题。
- 修复从模型测试预填过来的模型被上一次筛选词挡住的问题。
- 修复模型列表行固定高度导致大字号下文字被裁切的问题。
- 修复检测结果计数只统计成功项的问题，失败行同样算已出结论。
- 修复单个模型请求抛出异常会连累整批的问题。
