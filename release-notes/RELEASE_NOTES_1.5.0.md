# Relay Tester Android 1.5.0

发布日期：2026-10-03

## 更新内容

### 新增功能

- **检测历史**：每个模型留一条最近结论，最多 50 条，只存本机。
- **整轮进度**：进度按整轮题数计，换模型不再清零重来。
- **题目区按模型分块**：每个模型一块、一块三栏，块头显示序号、模型名与状态。
- **接收实时个数**：流式接收时显示「已收到 N 个整数」。
- **参考库改为可下载的检测包**：不再打进安装包，按需下载并按大小与 SHA-256 校验后安装，之后检测完全离线。
- **检测包由 GitHub Actions 每天与上游对齐**，数据真的变了才重建发布。
- **检测包格式升级**：与上游最新数据对齐，旧格式仍可安装与打分。
- **结果行重新设计**：信息分两行，动作按钮位置固定、不再左右跳。
- **结果行展开即全部内容**：评价卡与候选榜一次看全。
- 检测过程中也能复制题目提示词。

### 修复

- **安全 · 重定向只在同源内跟随**：以前会把认证头重发给 3xx 指向的任意主机，现在只在协议、主机、端口完全一致时继续且禁止降级。
- **安全 · 导入余额模板不再执行脚本**：校验只做静态语法检查。
- 修复冷启动首次进入指纹面板时自动更新检查被吞掉的问题。
- 修复双击「开始检测」可能并发两轮的问题。
- 修复重试要等整批跑完、重试的模型不对、以及逐题发送时重试抢跑的问题。
- 修复正在接收时重试按钮画得出却点不动的问题。
- 修复轮内补发的有效回答被整批回填盖掉的问题。
- 修复检测包更新中仍可开始检测的问题。
- 修复安装中断后检测包「失踪」的问题，现在主文件缺失自动回退到备份。
- 修复超过大小上限的检测包被整个读进内存的问题。
- 修复删除检测包时「备份删不掉」被误报为删除失败的问题。
- 解析检测包时补齐维度硬校验，并拒绝会造成整数溢出的尺寸。
- 修复部分中转站不支持流式回答时检测直接失败的问题。
- 修复「有效 3/3」与「有效 1/3」落在不同横向位置的问题。
- 修复快速双击「开始测试」启动两轮、取消后未完成行仍显示「进行中」的问题。
- 修复把「空模型目录」当成「模型已全部下架」的问题。
- 修复批量拉取异常导致面板卡在「获取中」的问题。
- 修复余额批量查询无上限扇出、查询超时参数未生效的问题。
- 修复系统字号放大到 2 倍时卡片裁切文字的问题。
- 「并行发送三题」整行合并为一个无障碍控件，图标按钮恢复 48 dp 最小触控。
- 修复「详情 / 收起」点击出现方形虚影、行内元素未对齐的问题。
