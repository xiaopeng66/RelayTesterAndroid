# Relay Tester Android 1.1.0

发布日期：2026-08-31

## 更新内容

### 新增功能

- **模型测试**：筛选与结果搜索支持 OR 分隔符，测试只作用于当前筛选范围。
- **高级测试**：每个供应商可独立保存快捷筛选词，支持增删与多选。
- **余额查询**：成功结果保留在本机，重启后自动恢复，且不含任何凭据。
- **配置备份**：快捷筛选词随加密备份一起迁移。
- **界面**：双栏余额卡重排，长金额不再被圆环挤压。

### 修复

- 模板、供应商或凭据变更时，同步清理失效的余额快照。
