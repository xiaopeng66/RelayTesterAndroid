# Relay Tester Android 1.7.3

发布日期：2026-10-06

## 更新内容

### 修复

- **供应商拖动排序真的能拖了**：拖动原本只挂在 44dp 的手柄图标上，起手抖动就断；现在按住整行任意位置拖动即可换位。
- **弹窗底部不再被裁掉**：供应商排序面板与余额模板编辑弹窗的「完成」和保存按钮以前落在屏幕外。
- **编辑供应商保存后自动关闭**：两处供应商编辑弹窗保存成功即收起，失败留在原地显示错误。
- **两条「已保存」提示一个规则**：余额页的保存提示以前被弹窗遮住看不见，现在与模型测试页同一组件、同一位置。
- **统一测试关掉弹窗后能回去了**：运行中入口保持可用并显示「统一测试中…」，主卡片给出「取消统一测试」。
- **运行中的按钮不再假装可用**：统一测试进行时，被拒绝的按钮与卡片改为禁用，余额页还会说明拒绝原因。
- **拉取模型失败有提示了**：结果直接印在拉取按钮下方，失败标红。
- **删除检测包先问一句**：全 App 最后一个没有确认的破坏性动作已补上确认框。
- **编辑入口不再埋雷**：切换供应商成功后才打开编辑弹窗，不再残留弹窗目标。
- **余额模板编辑器的错误看得见了**：校验失败的消息显示在编辑器窗口内。
- **旋转屏幕不再丢确认与勾选**：删除确认框与跨供应商检索的勾选随旋转保留。

### 优化

- **排序面板看得清也换得顺**：去掉上下箭头只留拖动，每行只显示模型名与序号，换位带动画。
- **余额模板编辑的选中项一眼可辨**：「配置方式」与「请求方法」选中项填主色、文字反白加粗。
- **查询脚本默认留空**：不再预填示例代码，按钮改为「填写 new-api 示例脚本」，点一下才填入。
