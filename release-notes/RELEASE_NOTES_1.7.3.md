# Relay Tester Android 1.7.3

发布日期：2026-10-06

## 更新内容

### 修复

- **供应商拖动排序真的能拖了**：拖动原本挂在每行右侧那个手柄图标上，它只有 44dp 宽，手指按住它再拖，起手的一点抖动就滑出它的边界，拖动当场断掉——按下去不动就是这个原因。现在整行都是把手，按住任意一行拖动即可换位，松手顺序立即保存。
- **两个弹窗的底部不再被裁掉**：供应商排序面板与余额模板编辑弹窗的卡片都被一段多余的顶部留白顶下去，底部的「完成」按钮和保存按钮落在屏幕外，得滚动才看得见。留白去掉，卡片高度按内容自适应。
- **编辑供应商保存后自动关闭**：模型测试页与余额查询页的供应商编辑弹窗，以前保存成功后还停在原地，要再点一次「关闭」；现在保存成功弹窗自己收起，保存失败则留在原地显示错误。
- **两条「已保存」提示一个规则**：余额查询页保存凭据后的黑色提示条以前画在页面底部的提示层，会被还开着的弹窗压在遮罩下面；现在与模型测试页同一条规则——同一个组件、同一位置（页面顶部居中）、同一时长，弹窗关掉后浮在页面上。

审阅三个主要功能时另修掉八处问题：

- **统一测试关掉弹窗后能回去了**：以前在「高级测试」里开跑统一测试，关掉弹窗后主界面既看不到进度，也没有取消的地方，连重新打开弹窗的按钮都是灰的——整屏按钮点得动却全无反应。现在运行中入口保持可用并显示「统一测试中…」，主卡片底部直接给出「取消统一测试」。
- **运行中的按钮不再假装可用**：统一测试进行时，「获取模型」「开始测试」「全选」「重测已选」「导出」以及余额页的供应商卡片都亮着，点下去却被静默丢弃。现在这些控件与运行状态同步禁用；余额页在被拒时还会说明原因（模型测试正在运行，暂时不能切换供应商）。
- **拉取模型失败有提示了**：在「高级测试」里点「拉取」，失败或空目录时以前没有任何可见反馈（提示被弹窗挡住）。现在结果就印在拉取按钮下方，失败标红。
- **删除检测包先问一句**：这是全 App 唯一没有确认的破坏性动作，误触一次就得整包重下。现在与「清空历史」等其它删除一致，先弹确认框。
- **编辑入口不再埋雷**：模型测试与余额查询页的「编辑」以前先记住弹窗目标再切换站点，切换被拒或保存失败时这个目标会残留——之后正常切换到该供应商时，编辑弹窗会自己弹出来。现在切换成功才会打开。
- **余额模板编辑器的错误看得见了**：模板校验失败的消息原本写进被弹窗遮住的那一层，等于没有提示；现在显示在编辑器窗口内。
- **旋转屏幕不再丢确认与勾选**：删除确认框、跨供应商检索的勾选、待移除来源等在旋转后会消失或清空（弹窗还在，内容没了）。现在这些状态与其它界面态一样随旋转保留。

### 优化

- **排序面板看得清也换得顺**：去掉上下箭头，只保留拖动；每行只显示模型名，与序号同一行高，顺序号改用主色加粗；两行交换位置时行是平移过去的，不再原地跳一下。
- **余额模板编辑的选中项一眼可辨**：「配置方式」与「请求方法」的选中态以前只比背景深一点点，现在选中项填主色、文字反白并加粗，未选中项加上描边——不再需要找那个勾才知道选了哪个。
- **查询脚本默认留空**：新建模板时输入框不再预填一整段示例代码，底部按钮也从「恢复 new-api 示例脚本」改成「填写 new-api 示例脚本」，点一下才填入；不点就是空的。
