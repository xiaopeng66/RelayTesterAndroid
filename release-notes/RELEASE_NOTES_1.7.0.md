# Relay Tester Android 1.7.0

发布日期：2026-10-05

## 更新内容

### 优化

- **更新下载锁定发布站点**：安装包与检测包的下载地址、以及每一跳重定向都必须是 HTTPS 且落在发布站点（GitHub 发布域）；明文降级或陌生站点一律拒绝。
- **下载先核对再落名**：安装包先落到 `.part`，核对字节数与 SHA-256 后才改名；交给系统安装界面前再校验签名证书与本应用一致，不一致直接删除。
- **摘要边下边算**：不再把整个安装包读进内存再核对；每次下载前清理上一次的残留文件。
- **凭据解不开时说清楚**：本机保存的凭据无法解密（系统密钥库被重置等）时给出明确提示并可重新输入，不再看起来像从没填过；导出配置备份时若凭据读不出会中止并点名供应商，不再静默写空。
- **更新检查遵守最低系统版本**：清单里声明需要更高系统版本的版本不会被下载。
- **安装失败分原因**：没有安装界面、安装权限被拒等分别说明，不再一律报「更新失败」。

### 修复

- 修复检测包数据异常（NaN / 无穷大、空模型）时崩在评分阶段的问题，现在解析时就给出原因。
- 修复余额查询脚本不返回时整次查询被挂住的问题（5 秒期限并说明超时）。
- 修复余额查询出错时把责任推给模板的问题，现在点名到具体凭据或请求头。
- 修复本机存储文件局部损坏时静默丢配置、并在下次保存时永久丢失的问题（现在启动即提示，且不覆盖原文件）。
- 修复流式回复没有上限、超长单行可能撑大内存的问题（聚合与单行上限 256 KB）。
- 修复旋转手机后打开的「关于与更新」与配置备份弹窗丢失的问题。
- 修复更新说明链接未校验就交给浏览器打开的问题，现在只接受发布站点地址。

## 说明

- 检测结果是**参考库内的封闭集合排序，不是身份证明**：不在库中的模型同样会得到最接近的候选，同家族相邻版本尤其难以区分。
- 应用自身更新的下载链路**不使用**供应商请求那条同源重定向策略：GitHub 的资产会跳到另一个官方域，这条链路改为逐跳校验发布站点白名单，且不携带任何凭据。
- 已知限制：余额查询所用的 QuickJS 原生库未按 16 KB 内存页对齐，16 KB 页设备上该功能可能无法加载（已登记在发布门禁中）。
- 移植自 [lm-detector](https://github.com/Ikaleio/lm-detector)（MIT License, Copyright (c) 2026 xqy2006），检测包算法与上游 `shared-detector-v1` 对齐，端侧实现与参数量化带来的差异已在 `THIRD_PARTY_NOTICES.md` 中如实声明。
