# Relay Tester Android 1.7.0

发布日期：2026-10-05

## 更新内容

### 优化

- **更新下载锁定发布站点**：安装包与检测包的下载地址与每一跳重定向都必须是 HTTPS 且落在发布站点，降级或陌生站点一律拒绝。
- **下载先核对再落名**：安装包先落临时文件，核对字节数与 SHA-256、签名一致后才交给系统安装。
- **摘要边下边算**：不再把整个安装包读进内存，每次下载前清理上次残留。
- **凭据解不开时说清楚**：本机凭据无法解密时给出明确提示并可重新输入，导出备份时凭据读不出会中止并点名供应商。
- **更新检查遵守最低系统版本**：声明需要更高系统版本的版本不会被下载。
- **安装失败分原因**：缺安装界面、权限被拒等分别说明。

### 修复

- 修复检测包数据异常（NaN、无穷大、空模型）时崩在评分阶段的问题。
- 修复余额查询脚本不返回时整次查询被挂住的问题。
- 修复余额查询出错时把责任推给模板的问题，现在点名到具体凭据或请求头。
- 修复存储文件局部损坏时静默丢配置的问题，现在启动即提示且不覆盖原文件。
- 修复流式回复没有上限、超长单行可能撑大内存的问题。
- 修复旋转手机后打开的「关于与更新」与配置备份弹窗丢失的问题。
- 修复更新说明链接未校验就交给浏览器打开的问题。
