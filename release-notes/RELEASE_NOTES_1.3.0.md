# Relay Tester Android 1.3.0

发布日期：2026-09-22

## 更新内容

### 新增功能

- **明文 HTTP**：支持只提供 `http://` 的自建站点，未写协议仍默认 HTTPS 并提示风险。
- **仅拉取模型**：供应商可开启「禁止测试」，只刷新模型列表、不发测试请求。
- **批量拉取**：失败时逐个列出供应商名称与原因。
- **模型名复制**：结果卡片与模型列表的模型名旁新增复制按钮。
- **高级测试**：模型卡新增目录刷新，已下架来源标注「已不存在」并可直接删除。
- **站点删除**：入口收敛到配置弹窗右上角，二次确认后删除。

### 修复

- 修复 HTTP 站点无法配置、余额查询始终失败的问题。
- 修复超时固定为 10 秒、不随配置缩放的问题。
- 修复批量拉取失败时看不出是哪些供应商的问题。
- 修复删除正在编辑的供应商后配置弹窗残留的问题。
- 修复移除来源后「已不存在」标记残留的问题。
- 修复移除最后一个来源后留下空条目的问题。
- 修复结果卡片对齐与长供应商名被遮挡的问题。
- 修复快捷筛选卡片的删除叉号不居中。
