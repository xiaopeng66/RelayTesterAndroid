# Relay Tester Android 1.8.0

发布日期：2026-10-12

?> 对比基准：GitHub 上一个发行版 **v1.7.3**。本版一次性覆盖 v1.7.3 → 1.8.0 的全部变化。

## 更新内容

### 新功能

- **动画测试（全新）**：可对任意供应商/模型生成 HTML+SVG 动画，生成过程实时显示文档与思考链，完成后直接在应用内播放。
- **动画多模型一次启动**：勾选多个模型后点一次「开始生成」即同时各起一条会话，互不阻塞、各自结算。
- **动画模型搜索**：选择模型时可输入关键词本地过滤，只筛列表、不发请求、不影响已勾选。
- **成功即显示截图**：动画成功后在记录行用缩略图替代文字状态，一眼认出这条做出了什么。
- **分享动图**：把动画录成 GIF 并通过系统分享给其它应用。
- **浏览器打开**：把生成的页面交给真实浏览器查看。
- **高级测试（跨供应商统一测试）**：同一模型可配多个供应商来源并分别验证连通性，带来源管理与结果对比。
- **余额查询**：按供应商配置查询模板（表单或脚本），支持单个、逐卡刷新与批量查询。
- **指纹检测**：以固定题组探测模型身份倾向，支持三题并行、逐题重试、结果历史与检测包在线更新。
- **配置备份与导入**：整机配置可加密导出与导入，含凭据。

### 优化

- **动画操作条尺寸统一**：四个次要动作改为固定等边方按钮，主操作压到紧凑高度，取消保持描边。
- **跨功能并行**：模型测试、动画、指纹、余额四类互不阻塞，可同时进行（高级测试不受限制）。
- **余额按供应商并发**：单卡刷新与批量查询可同时在途，只按供应商去重。
- **禁止测试的供应商不再参与**：下拉、默认选择、全量检索与所有发起路径都排除。
- **动画记录有上限**：保留最近 20 条，超出淘汰最旧，当前打开的那条始终保留。
- **导出文件自述范围**：结果 JSON 记录导出时的筛选条件，避免「比屏幕多出很多行」的误解。
- **动画生成更耐上游波动**：断连自动重试、空正文自动重发、重试成功即归零。
- **动画预览与源码窗格**：整行显示、上下留白一致，长文档不再露出半行。
- **思考过程可回看**：上滑阅读时停止裁剪，回到末尾恢复。
- **检测包在线更新**：可检查、下载、删除检测包，并提供模型支持列表。
- **应用自动更新**：更新页可检查并下载安装新版本。

### 修复

- **上游「HTTP 200 但没有可用的文本内容」定位并缓解**：实测确认为中转网关约 120 秒硬截断（思考未结束时静默断流、无结束帧），现已纳入自动重试并如实报出「上游在思考阶段中断」。
- **检测包按钮不再「可点却无反应」**：启动读期间正确禁用，被拒时按占用类型给出准确原因。
- **高级测试检索的拒绝不再被弹窗盖住**：空关键词与无可检索供应商都在弹窗内可见。
- **目录卡片不再把禁止测试的供应商显示为「已删除供应商」**。
- **禁止测试的供应商不能再加为来源**：两条入口统一校验。
- **高级测试与普通测试不再互相静默阻断**：UI 与判定一致，点击即生效。
- **无效供应商启动不再先清空勾选**：校验前置、拒绝时保留选择。
- **备份导入不再拒绝自己导出的配置**：Prompt 上限在保存与导入两侧统一（此前导入侧更小，会报「超出安全长度」）。
- **动画提示词与测试 Prompt 加上长度上限**：粘贴超长文本会被明确拒绝或夹紧，不再原样发出或写入配置。
- **供应商拖动排序稳定**：拖动跟随手指、边缘自动滚动，不再来回跳位。
- **弹窗在运行中不再假装可用**：被拒绝的操作直接禁用并说明原因。
