# Relay Tester Android 1.7.2

发布日期：2026-10-06

## 更新内容

### 新功能

- **供应商排序**：模型测试页「供应商」标题旁新增排序按钮（有两个以上供应商时出现），打开后可按住每行右侧手柄拖动，也可用上下箭头逐位移动，顺序在所有页面统一生效——模型测试的卡片、余额查询的卡片、指纹检测的供应商选择都按同一顺序排列，排好后立即保存。

### 修复

- **推理模型不再被误判为「流式响应过大」**：指纹检测遇到会先输出一大段思考内容的模型时，以前会报「流式响应过大（超过 256 KB）」而放弃这道题。思考内容不是回答，现在不再计入上限，这类模型可以正常检测。

### 优化

- **编辑余额模板不再跳回页面顶部**：编辑模板与新建模板改成弹窗，盖在余额页上方；保存或返回后仍停在离开前的位置，不再每次都回到列表顶端。
- **「选择模型」里的提示语缩短**：手动输入不在供应商列表中的模型名时，原来那句长提示会被省略号截断，现在改成「不在列表，直接检测」，完整可读。
