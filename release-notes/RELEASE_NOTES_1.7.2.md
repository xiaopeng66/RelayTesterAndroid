# Relay Tester Android 1.7.2

发布日期：2026-10-06

## 更新内容

### 新功能

- **供应商排序**：模型测试页可拖动调整供应商顺序，模型测试、余额查询与指纹检测三处按同一顺序排列。

### 修复

- **推理模型不再被误判为「流式响应过大」**：会先输出大段思考内容的模型不再因此放弃检测。

### 优化

- **编辑余额模板不再跳回页面顶部**：编辑与新建模板改为弹窗，保存或返回后仍停在离开前的位置。
- **「选择模型」提示语缩短**：改为「不在列表，直接检测」，完整可读。
