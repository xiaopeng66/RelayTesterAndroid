# Relay Tester Android 1.0.0

发布日期：2026-08-30

## 更新内容

### 新增功能

- **模型测试**：支持 Chat Completions、Responses 与 Anthropic Messages 三种协议。
- **高级测试**：支持模型拉取、并发批量测试、筛选排序、复制与结果导出。
- **余额查询**：内置 new-api 模板，支持模板增删改与单站、全部站点查询。
- **配置备份**：全部配置可加密导出与导入为 `.rtbackup` 文件。
- **供应商管理**：多个供应商各自维护地址、协议、API Key 与测试参数。

### 修复

- 优化启动期间后台数据与密钥的调度。
- 修复极端存储失败时旧密钥被过早删除。
- 修复保存失败后状态误报。
- 修复上游错误脱敏不完整。
