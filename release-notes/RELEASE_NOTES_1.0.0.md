# Relay Tester Android 1.0.0

发布日期：2026-08-30

## 更新内容

### 新增功能

- **模型测试**：支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages 三种协议。
- **高级测试**：支持模型列表拉取、并发批量测试、限速、重试、筛选、排序、复制与结果导出。
- **余额查询**：内置 `new-api` 模板，支持新建、复制、编辑、删除模板；单站点与全部站点余额查询可用。
- **配置备份**：完整配置导入导出，包括供应商、模型、测试参数、模板与凭据，输出用户密码加密的 `.rtbackup` 文件。
- **供应商管理**：支持多个供应商各自维护名称、中转站地址、协议、API Key、模型列表与测试参数。

### 修复

- 优化启动期间后台数据与 Keystore 的调度。
- 修复极端本地存储失败时旧密钥被过早删除的问题。
- 修复保存失败后状态误报的问题。
- 修复上游错误脱敏不完整的问题。
