# RelayTester UI 修复方案（评审稿）

> 版本：2026-09-02  
> 阶段：方案已实施，以下记录与验收结果同步更新  
> 范围：模型测试面板、余额查询面板、模型来源弹窗及结果筛选区域  
> 原则：不改变现有业务能力、数据格式和页面主布局；新增能力只通过紧凑控件和弹出面板承载。

## 1. 当前检查结论

当前实现的主要问题不是功能缺失，而是新增控件占用了原卡片的布局空间，导致卡片高度、文本基线和弹窗边界发生变化。问题集中在以下几类：

1. 供应商卡片把“站点配置”和“查询凭据”做成带文字的底部按钮，挤压了原有内容并改变卡片高度。
2. 测试参数区域右侧按钮文案过长，和标题同一行时触发换行；“模型来源”这个名称也没有体现这是高级测试能力。
3. 模型来源弹窗使用固定最大高度和多行按钮堆叠，底部圆角、操作区和来源添加区在小屏幕上不完整或拥挤。
4. 已配置模型卡片缺少清晰的信息层级、来源分隔和编辑入口；全局“一键测试全部”不符合“单个模型独立测试”的新交互要求。
5. 模型测试结果卡片的 Checkbox 使用完整 48dp 布局尺寸，导致卡片变高；失败结果把错误类型和错误消息重复显示，出现“请求超时”两行。
6. 模型过滤目前以 `|` 表示 OR，与要求的英文半角逗号不一致；快捷筛选 Chip 的删除图标过大且单栏排列，空间利用率低。

## 2. 统一设计约束

### 2.1 尺寸与触控

- 保留现有供应商卡片和余额卡片的原始高度常量，不因新增按钮增加 `height`、`padding` 或底部操作行。
- 图标视觉尺寸统一为 20–22dp；图标按钮的可点击区域保持 Android 推荐的最小 48dp，通过透明点击区域而不是放大图标实现。
- 所有新增按钮使用 Material 图标，不使用 Emoji；图标必须配置清晰的 `contentDescription`。
- 新增控件的 pressed/selected 状态只改变颜色、边框或阴影，不改变布局边界，避免选中卡片“卡顿”或跳动。

### 2.2 间距与文本

- 统一采用 4/8dp 间距节奏；卡片内边距、标题与副标题间距、来源行间距固定化。
- 模型名称、供应商名称和测试状态默认单行显示，超长文本使用省略号；不允许因为错误消息或状态标签把卡片撑高。
- 需要同时表达多个字段时，优先使用一行紧凑的元数据串，字段之间用 ` · ` 分隔。

### 2.3 状态和兼容性

- 点击供应商卡片仍然只负责切换供应商；双击行为继续分别触发拉取模型或查询余额。
- 弹窗取消或返回时，所有未保存输入只保留在临时草稿中，不写入持久化配置。
- 原有已保存配置继续可读。过滤表达式迁移时新格式使用逗号，但读取旧数据时可兼容 `|`，避免升级后筛选失效。

## 3. 供应商卡片修复

### 3.1 模型测试面板的供应商卡片

将“站点配置”改为卡片右上角的图标按钮：

- 使用 `Edit` 或 `Settings` 轮廓图标，视觉尺寸 20–22dp。
- 采用 `Box` 叠加在卡片内容右上角，按钮区域为 48dp，但不参与 Column 的垂直测量；卡片标题和模型数量信息保持原位置。
- 右上角按钮与卡片边缘留 4–8dp 内缩，避免图标贴边；标题右侧预留同等空间，防止长供应商名称被按钮覆盖。
- 点击图标打开原有站点配置弹窗；点击卡片其他区域仍切换供应商，双击仍刷新模型。
- 删除卡片左下“站点配置”文字按钮及说明文案中的“从卡片左下进入”。

### 3.2 余额查询面板的供应商卡片

将“查询凭据”改为供应商名称后的图标按钮：

- 名称后加入 8dp 左右间隔的 `Edit` 图标，不显示文字。
- 余额圆环继续固定在卡片右侧；名称、编辑图标和圆环之间设置最小 12dp 间距，名称过长时优先省略名称，不挤压圆环。
- 保持 `BALANCE_SUPPLIER_CARD_HEIGHT` 不变，删除底部凭据操作行及其占用的 `Spacer(weight = 1f)`。
- 凭据图标点击打开原有凭据弹窗；卡片主体点击和双击逻辑不变。

### 3.3 选中效果

采用稳定的“容器色 + 边框色 + 轻微阴影”组合：

- 选中状态使用 `animateColorAsState` 过渡到主题 `secondaryContainer`，未选中回到 `surface`。
- 选中边框使用主题 `primary`，未选中使用 `outlineVariant`；不要通过改变 padding、宽度或高度表达选中。
- 过渡时长控制在 120–180ms，点击反馈使用 Material ripple，确保快速连续切换时不会闪烁。
- 选中状态保留无障碍语义 `selected = true`，并在内容描述中说明可双击刷新。

## 4. 测试参数区域

### 4.1 右侧入口

- 入口文案从“模型来源”改为“高级测试”，含义改为“打开跨供应商模型来源与独立测试面板”。
- 使用紧凑 `OutlinedButton`：图标为 `Tune`/`Layers`，按钮高度 40–44dp，水平内边距 10–12dp，文字不超过四个汉字。
- 标题区域使用 `weight(1f)`，按钮设置 `widthIn(min = 96.dp, max = 116.dp)`；在 375dp 宽度设备上标题仍保持单行。
- 如可用宽度不足，按钮退化为仅图标的 48dp `IconButton`，通过 tooltip/contentDescription 保留“高级测试”语义，不允许标题换行。

### 4.2 过滤文案

- 模型名过滤和测试结果搜索的标签改为“模型名过滤（逗号分隔，OR）”和“搜索测试结果（逗号分隔，OR）”。
- 占位示例改为 `gpt,claude`。
- 快捷筛选说明同步改为“多个词用英文半角逗号 `,` 表示 OR”。

## 5. “高级测试”弹窗重构

### 5.1 弹窗容器

使用自定义 `Dialog` + `Surface`（或等价 Material 容器），不要继续让 `AlertDialog` 的默认按钮区承担全部布局：

- 宽度约为屏幕 92–94%，高度不超过可用窗口高度的 88%。
- Surface 使用完整圆角；内部按“标题、滚动内容、固定底部操作栏”三段布局。
- 只有中间内容区滚动，底部操作栏始终可见；内容区末尾额外保留 16dp bottom padding，避免圆角边框被裁剪。
- 处理状态栏、导航栏和键盘 Insets；键盘弹出时仍可滚动到模型名称和来源列表。

### 5.2 来源添加区

按操作流程分组，而不是把六个按钮纵向堆叠：

1. 第一行：供应商下拉框（整行）。
2. 第二行：模型下拉框（权重更大）+ “拉取”图标按钮（固定 88–96dp）。
3. 已添加来源显示为紧凑列表，每行展示“供应商 · 模型”，右侧为 32–36dp 视觉删除图标；行与行之间使用 `HorizontalDivider`。
4. 底部固定操作栏并排放置“关闭”“添加来源”和“保存模型来源”，其中添加来源为次按钮、保存为主按钮；当当前模型未选择时添加来源保持禁用，不留空白占位。

这样可以消除“添加来源左边空着”的现象，也不会让保存按钮被滚动内容挤出屏幕。

### 5.3 编辑模式状态机

弹窗需要区分“新增”和“编辑”两种草稿状态：

- 新增：模型名称为空、来源列表为空，保存后创建新 ID。
- 编辑：点击已配置卡片的编辑图标后，将该条目的 ID、模型名称和来源复制到临时草稿；标题显示“编辑模型来源”。
- 编辑期间添加或删除来源只修改草稿；点击关闭、返回或系统返回时丢弃草稿。
- 点击保存时按原 ID 覆盖条目，不能生成重复卡片；持久化失败时恢复保存前列表并提示错误。
- 保存成功后清空编辑状态并保留弹窗，便于继续添加下一条模型。

## 6. 已配置模型卡片

### 6.1 信息层级

- 顶部第一行：模型名称使用 `titleMedium`/半粗体，最多一行；右侧按“编辑、测试、删除”顺序排列图标按钮。
- 模型名称下方只显示“来源数 · 最近测试时间（如有）”等必要摘要，不再显示“可用 N · 失败 N”这类重复统计描述。
- 每个来源独立成一行：供应商名称、实际模型 ID、状态和延迟/HTTP 信息；来源行之间显示 `HorizontalDivider`，首行前不显示分隔线。
- 状态颜色不能作为唯一信息，必须同时显示“未测试 / 可用 / 失败”等文字。
- 错误详情默认单行省略；点击卡片或状态可展开完整错误（若当前产品暂不需要展开，则至少保证卡片高度固定）。

### 6.2 操作和测试

- 删除全局“一键测试全部”按钮。
- 每张模型卡片增加编辑按钮：加载当前条目到上方编辑区，保存后覆盖原卡片；未保存不影响原卡片。
- 编辑按钮旁增加测试按钮，只测试该卡片的全部来源；测试期间该卡片按钮禁用并显示进度，其他卡片仍保持可浏览。
- ViewModel 层保留统一测试能力作为可复用执行器，但 UI 入口改为 `startUnifiedCatalogTest(entryId)`，目标列表只包含指定条目的来源。
- 测试完成后仅更新对应条目的结果，不清空其他条目的结果。

## 7. 模型测试结果卡片

### 7.1 Checkbox 与固定高度

- Checkbox 保持 48dp 可触摸区域，但通过 `Box(Modifier.size(36.dp), contentAlignment = Center)` 放置较小视觉控件；不要把整张卡片的 padding 增大。
- 结果卡片使用固定或受控最小高度，内容行 `verticalAlignment = CenterVertically`；模型名与状态行均 `maxLines = 1`、`softWrap = false`。
- 失败详情与元数据采用单行省略或折叠，不允许长错误文本把卡片撑高。
- Checkbox、状态色点、模型名和状态标签在同一条主行对齐，上下内边距保持一致。

### 7.2 “请求超时”重复显示修复

当前重复来自两处文本同时输出：一处是 `HTTP … · 错误类型`，另一处是 `error.message`。改为统一错误摘要函数：

- 有 HTTP 状态时显示 `HTTP 408 · 请求超时`；没有状态时只显示 `请求超时`。
- 只有当 `error.message` 与错误类型文案不相同且包含额外诊断信息时，才显示第二行；完全相同则去重。
- 网络异常、认证失败等错误沿用同一规则，避免出现“认证失败 / 认证失败”的重复。
- 为该摘要函数增加单元测试，覆盖 HTTP 408、无状态超时、重复消息和自定义消息四种情况。

## 8. 快捷筛选卡片

- 从单栏 `FlowRow` 改为两栏网格（每项约占可用宽度的一半，间距 8dp），小屏仍保持左右两列，不出现横向滚动。
- 每个筛选项采用紧凑卡片或 AssistChip：文本左对齐、最多一行省略；右上角放 16–18dp 的 `Close` 图标。
- 删除图标的视觉尺寸缩小，但点击区域仍不小于 40–48dp；点击文本区域执行筛选，点击右上角只删除，不触发筛选切换。
- 选中状态使用轻量背景色和边框变化，不改变卡片高度；删除时使用 120ms 以内的淡出/收缩动画，支持系统减少动态效果设置。

## 9. 数据与 ViewModel 改造边界

1. `ModelCatalogEntry` 增加“编辑中的条目 ID”仅作为 UI 临时状态，不写入持久化模型。
2. 将当前 `saveModelCatalogEntry(name, sources)` 拆为新增/更新两个明确入口，或增加可选 `entryId` 并在保存时按 ID 替换。
3. 将统一测试入口改为接收 `entryId`；执行器仍复用现有并发、取消、进度和结果模型。
4. 过滤解析器以英文半角逗号为主分隔符，同时兼容历史 `|`/全角符号；保存新配置时统一写成逗号语义。
5. 不修改供应商密钥、余额凭据、查询脚本和备份文件的字段含义；新增的编辑状态不进入备份。

## 10. 分阶段实施顺序

### 阶段 A：纯布局和图标

先处理两个供应商卡片、测试参数入口、结果卡片 Checkbox 和快捷筛选网格。该阶段不改数据结构，完成后即可进行视觉回归。

### 阶段 B：弹窗容器与模型来源编辑

重构弹窗滚动/固定操作区，加入新增/编辑草稿状态，调整来源列表和按钮排布。完成新增、取消、编辑、保存覆盖、删除的交互测试。

### 阶段 C：单模型测试与错误摘要

切换为卡片级测试入口，移除全局测试按钮，加入固定高度错误摘要及去重逻辑。

### 阶段 D：兼容性和回归

验证旧配置导入、旧过滤表达式、余额脚本、供应商切换、双击刷新、模型勾选测试、取消测试和应用重启恢复。

## 11. 验收标准

- 375dp 宽度手机上，模型测试和余额查询供应商卡片高度与修复前一致；站点配置/查询凭据只显示图标。
- 供应商名称、编辑图标、余额圆环之间无重叠，快速切换选中状态无跳动。
- 测试参数标题保持单行，入口显示“高级测试”；弹窗底部圆角和关闭/保存按钮始终完整可见。
- 模型来源添加区无空白占位，已配置模型卡片支持编辑、单卡测试、删除，保存失败不丢失原配置。
- 已配置模型摘要不再显示“可用 N · 失败 N”；每个来源之间有可见分隔线，模型名明显突出。
- 结果卡片 Checkbox 视觉更小但可点击区域足够，模型名和测试结果单行显示；“请求超时”不重复出现。
- 模型过滤和结果搜索示例、帮助文案均使用英文半角逗号；旧的 `|` 配置仍可用。
- 快捷筛选为双栏，删除叉号位于右上角且不抢占筛选点击；浅色/深色主题下文字、边框和状态对比度可读。
- 运行 `git diff --check`、单元测试和 `:app:assembleDebug` 均通过，并在 API 34 模拟器完成基本点击回归。

## 12. 实施结果

本方案已按阶段 A→D 实施到当前工作区：

- 阶段 A：供应商卡片图标入口、原始高度恢复、选中状态动画、测试参数“高级测试”入口、结果 Checkbox 和快捷筛选双栏布局已完成。
- 阶段 B：高级测试弹窗改为固定底部操作区，新增/编辑草稿、来源分隔、保存覆盖和删除已完成。
- 阶段 C：全局“一键测试全部”入口已移除，模型卡片提供编辑、单卡测试和删除；统一执行器按条目 ID 测试，支持取消和进度显示；错误摘要已去重。
- 阶段 D：过滤解析改为英文半角逗号优先并兼容旧 `|`，README 与本文件同步更新。
