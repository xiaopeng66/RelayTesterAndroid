# 1.6.0 最终复查记录（2026-10-04，覆盖发布）

本页是 1.6.0 这一条公开发行线在**覆盖发布前最后一遍**的完整检测记录。这一轮不新增功能，做的是三件事：按用户清单做全仓文案精简、修四处界面/行为问题、把「自动检查更新」的节律改成「打开 App 一次 + 常开时每 6 小时一次，且不与手动检查竞争」。发行说明见 [`RELEASE_NOTES_1.6.0.md`](../RELEASE_NOTES_1.6.0.md)；文案逐条清单见 [`UI_TEXT_TRIMMING_PLAN.md`](UI_TEXT_TRIMMING_PLAN.md)；本页只记录**做了什么、怎么验的、还剩什么**。

- 构建：`versionCode 10600` / `versionName 1.6.0`（optimized 变体，R8 + 资源收缩，**正式发布密钥**签名，包名 `com.relaytester.app`）
- 产物：`app/build/outputs/apk/optimized/app-optimized.apk`
  - 2,958,267 字节，SHA-256 `dee706ec89ee3e32db4b7603b35d1e3113466904ace7ace42547ad0c4bab1b23`
  - 这是**实际发布的那一份**：`adb pull` 从设备上拉回的 `base.apk` 与这份构建件 **逐字节相同**（同为 2,958,267 字节、同一 SHA-256），设备走查跑的就是它。
  - Android 构建不可字节复现：本轮的**字节数与首次发布完全相同**（都是 2,958,267），但 SHA-256 与首次发布那一份不同。所以本页记录的是真正上传并回读核对过的产物，产物与源码的一致性另由 `tools/verify_apk_wording.py` 从包内字符串双向核验。
- 覆盖发布：公开发行线仍是单独一个 1.6.0 / 10600，版本号不变。因此这次只是把同一版本号下的安装包换成新构建（取舍见第 5 节）。

## 3. 自动检查的节律（本轮按用户语义改动）

改动前只在「启动 App」与「打开更新弹窗」各查一次（6 小时节流）。改成：

- **打开 App 查一次**（保留，仍按落盘时间戳做 6 小时节流，避免冷启动连查）；
- **新增常驻定时器**：App 常开时每 6 小时静默查一次（间隔可注入，便于用虚拟时间测试）；**去掉「打开弹窗再查一次」这个触发**——少一个入口就少一次竞争；
- **不与手动检查竞争**：手动点「检查更新」时，如果正在飞的是静默检查就**取消它**、改成可见检查（按钮转圈）；如果正在飞的是可见检查就忽略这次重复点击。检测包的自动/手动本来就是两套互斥守卫，未改。

这几条在设备上看不到 6 小时的窗口，全部由单测钉住（第 4 节变异红证逐条对应）：`coming up makes one request, not one from the launch check and one from the timer`、`the periodic check wakes when the window is due`、`a wake never re-checks inside the timer's minimum wait`（60 秒最小唤醒间隔）、`a check in flight keeps the timer from starting another`（`busy()` 守卫）、`the button takes over from a check running by itself`（并断言静默那一次**被取消**而不是被晾着，靠 `FakeHttpFetcher.cancellations` 计数）。

## 5. 未做与两处取舍

- **未做真机走查**（与历轮一致，设备证据全部来自 API 35 模拟器）。
- **覆盖发布 = 版本号不变**：因此**已经装了首次发布那份 1.6.0 的人，App 内不会收到更新提示**（版本代码相同，比较结果是「已是最新」），要手动重新下载；而装在 ≤1.5.0（或用重建后的同包名同签名历史版本）的人仍会被提示升到 10600，拿到的就是这次的新构建。这是用户选的、也是本仓一直用的「同号覆盖」惯例。
- **动作按钮盒子 40dp 低于 48dp 的无障碍建议触控尺寸**（用户明确要求挤紧、图标不许变大），已在按钮注释里记下这个取舍；图标尺寸与读屏文案都不动。
- **涟漪去除只能由代码事实说明**：本想做「按下前/按住中同一区域零像素差异」的红证，四个按钮区域实测 0/75950 个像素不同；但同一套探针去按**普通 M3 按钮**同样是 0 差异 —— 说明该手势注入在 Compose 里根本画不出按下态，**探针是瞎的，这个 0 不能当证据**。设备上没有可用的观测手段。
- **旧按钮标签无法由清单证明**：`删除已安装的检测包` 仍在同一句错误信息里（见第 1 节末），其形态由第 2 节第 1 条的量测确认。
